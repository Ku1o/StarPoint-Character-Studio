# 稿主体验与工坊优化参考材料

从[素材准备指南](01-稿主资源提供指南.md)和[填写模板](starter-pack/00-需求单.md)开始；复制[starter-pack](starter-pack/README.md)整理原稿。指南与需求单由 `production_brief.author_readme()` / `author_submission_form()` 从工坊同一 schema 生成，维护时重新生成，避免另立一张全部必须的清单。

作者填写自然语言意图，明确谁补充、复用来源、派生母版和不适用理由；制作方接入仍单独待核。工程导出的 README 和交接 JSON 会带当前状态及具体问题。没有配音可明确声明，一张母版可派生 UI 小图，进化形态可复用。

## 目录

| 文件 | 说明 |
| --- | --- |
| `01-稿主资源提供指南.md` | 同 schema 生成的作者指南、责任声明、当前缺项与下一步 |
| `02-稿主提交前自检清单.md` | 提交前逐条勾选（含基础态纯本体帧、`_sp` 合成帧单独声明、获取演出声明等） |
| `03-角色工坊交互改进提案.md` | 历史改进提案，功能状态以实际页面和检查结果为准 |
| `starter-pack/` | 稿主素材包最小模板（需求单、自检清单、动作说明、特效声明、语音对照表、命名说明） |
| [资源用途与裁剪参考](资源用途与裁剪参考.md) | 制作方核对界面用途、裁剪与形状遮罩，参考尺寸不作为作者原稿接收限制 |

## 背景

这些内容来自一次真实角色制作的复盘（基础帧被合成帧污染、UI 裁剪与形状遮罩缺失、
能力行空值与描述文本问题等），用于把"靠人记的经验"转化为工坊内的校验与提示。
其中已在工坊落地的部分见仓库根的 `CORE-PROVENANCE.md`「门禁归属表」。
