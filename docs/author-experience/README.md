# 稿主体验与工坊优化参考材料

本目录收录"稿主资源提供"相关的指南、自检清单、工坊交互改进提案与素材包模板。

**定位**：这些材料主要作为**后续工坊改造升级的输入**（由 AI/维护者据此优化导入、校验与提示流程），
不是对外发放给稿主的正式文档；如需发给稿主，应另行精简与措辞确认。

## 目录

| 文件 | 说明 |
| --- | --- |
| `01-稿主资源提供指南.md` | 必交/可选资源清单、目录与命名规范、格式尺寸要求、每类资源在游戏中的用途 |
| `02-稿主提交前自检清单.md` | 提交前逐条勾选（含基础态纯本体帧、`_sp` 合成帧单独声明、获取演出声明等） |
| `03-角色工坊交互改进提案.md` | 具体到"工具/时机/文案"的改进提案（导入提示、声明字段、检查项、包内必读） |
| `starter-pack/` | 稿主素材包最小模板（需求单、自检清单、动作说明、特效声明、语音对照表、命名说明） |

## 背景

这些内容来自一次真实角色制作的复盘（基础帧被合成帧污染、UI 裁剪与形状遮罩缺失、
能力行空值与描述文本问题等），用于把"靠人记的经验"转化为工坊内的校验与提示。
其中已在工坊落地的部分见仓库根的 `CORE-PROVENANCE.md`「门禁归属表」。
