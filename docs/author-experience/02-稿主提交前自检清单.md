# 稿主提交前自检清单

本清单配合同 schema 生成的需求单和工坊作者责任声明使用；勾选表示意图已说明，游戏接入由制作方核验。

- [ ] 原稿文件名、目录与可编辑源文件保留；候选未覆盖原稿。
- [ ] 角色、形态差异和玩法意图已写清；未定数值标待协商。
- [ ] 每项制作所需用途已选择作者责任声明；明确复用有来源，可派生有母版，不适用有理由。
- [ ] 一张母版派生小图、进化复用已说明，没有为了填满清单重复绘制。
- [ ] 原精灵图每格尺寸、格号起点、帧用途与身体足底已说明。
- [ ] 动作时长、循环、返回动作、纯本体与合成帧分开；缺动作有明确补画或映射意图。
- [ ] 技能起手、命中和结束的顺序、位置、跟随对象与伤害判定分开。
- [ ] 声音原稿保留完整句尾；已有语音有实际入口、完整原文和形态/随机/条件关系。
- [ ] 无配音、以后补或复用范围明确；音效另作声明。
- [ ] 获取全文保留词义和手动换行；排版候选有差异，近似预览未当作实际验收。
- [ ] 玩家铭牌按需求选填，与角色资料头衔分开；无需求可标不适用。
- [ ] 工程与制作交接一起保留；作者补充、制作方待核、实际已验范围分别列明。

未勾选的条目可以交给制作方讨论，但需写明未知和需要协助的内容。未标注不等于通过，预览、编译与游戏内验收分别记录。
