# 稿主提交前自检清单

用法：复制本文件到你的素材包里，逐条勾选；不适用的条目请在方括号后写“不适用 + 原因”。
**每一项都与“素材会不会被用错地方”直接相关；勾不上的条目请先补，不要交完再补。**

---

## A. 通用

- [ ] 我已经拿到制作方给的目标角色“角色专用参考包”，并确认了它的资源版本；
- [ ] 我填写了《需求单》（`00-需求单.md`）：目标角色、基础/进化是否都改、复用哪些内容、素材来源与授权；
- [ ] 素材包里没有混入模板角色里本来就有、我没有改动的整套资源（没改的写了“复用”）；
- [ ] 所有文件名只用中文/英文/数字/下划线/连字符，没有空格和特殊符号；
- [ ] 同一个动作的帧按 `_001`、`_002`… 编号，排序即播放顺序；
- [ ] 每个动作的 `动作说明.md` 已填写：名称、用途、帧数、帧顺序与停留、循环方式、定位方式、是否含附属物；

## B. 立绘与界面图

- [ ] 基础与进化立绘都是透明 RGBA PNG，分辨率不低于 1440×1920；
- [ ] 人物、武器、衣摆没有被画布裁断，四周留了透明边；
- [ ] 两张立绘是同一角色，脸型、发色、服装关键特征一致；
- [ ] 只有一张母版时，我已在需求单里写明“另一形态沿用基础/允许复用”；
- [ ] 我说明了五个重点面板的取景要求（图标=脸部特写、编队=头胸腰、技能插入图=宽幅半身、技能指引=竖向头胸、技能连锁=脸部）；
- [ ] 需要特殊表情/构图/文字的用途，我已提供单独源图并注明“禁止从母版自动裁切”；
- [ ] 我说明了哪些用途需要形状遮罩（技能指引=锥形、技能连锁=六边形、圆形头像=圆、圆角类=圆角矩形），或确认“按官方形状自动烘焙”；
- [ ] 我确认构图没有把重要内容贴到画布边缘（形状遮罩会裁掉框外像素）；

## C. 像素动画

- [ ] 11 个默认状态（待机/前进/后退/技能准备/胜利/倒下/灵魂出现/灵魂待机/复活/获取登场/获取定格）逐项确认了“提供”还是“复用模板”；
- [ ] **基础状态（待机/前进/后退/胜利/倒下/灵魂出现/灵魂待机/复活）提供的是纯本体帧**，不含召唤物和附加元素；
- [ ] 如果某些状态要带召唤物/附属物，我已**单独提供合成帧**（文件名带 `_sp` 或同等清晰后缀），并在动作说明中写清对应状态和出现时机；
- [ ] 合成帧与纯本体帧没有混在同一目录里直接一起导入；
- [ ] **获取演出（`special_land` / `special_pose`）是否带召唤物，我已二选一写明**；
- [ ] 每个状态的帧数、顺序、每帧停留（如 6/12/6）、循环方式我逐一写清，而不是让制作方猜测；
- [ ] 新增或删改的动作（官方模板里没有的）我提供了完整帧组和时间信息；
- [ ] 同动作所有帧画布一致、脚底（或中心点）位置一致；
- [ ] 单帧 PNG 透明背景、单边不超过 1022 像素，未预先放大；
- [ ] 没有交 PSD/GIF/APNG/视频；整张精灵图已附切片说明（单格尺寸、留白、间隔、行列顺序）；

## D. 技能特效与音效

- [ ] 主动技能场上特效我已三选一：复用（写明角色）/ 重皮（给模板+配色）/ 完全原创（给四件套或骨架）；
- [ ] 原创特效提供的是可用四件套或指定骨架 + 对应贴图，而不只是概念图、截图或 GIF；
- [ ] 技能音效按用途标注（施放/命中/蓄力/移动/其他）；
- [ ] 每个音效写明了绑定关系（哪个动作、第几帧开始、是否循环、是否淡出）；
- [ ] 音频是标准可播放的 WAV/MP3/OGG，没有自行转码或改封装；
- [ ] 沿用官方音效的部分已写“复用”，没有重复提供文件；

## E. 语音与台词

- [ ] 语音按入口分目录：`ally/`（加入、进化）、`battle/`（战斗）、`home/`（主页）；
- [ ] 每条语音在 `语音对照表.csv` 中有一行：文件、入口分类、用途、台词文本；
- [ ] 台词文本填写完整（不依赖“制作方应该能听懂”）；没有文本的语音已注明“暂无台词”；
- [ ] 明确说明哪些语音复用模板、哪些是替换；
- [ ] 语音使用授权已确认（尤其是非本人声线、AI 声线）；
- [ ] 不需要的登录语音、剧情语料没有塞进包里；

## F. 剧情（如适用）

- [ ] 剧本文字、出场顺序、表情原图、横幅源图齐全；
- [ ] 不需要剧情的话，素材包里没有 `story/`、`words/` 目录；

## G. 打包交付

- [ ] 已删除模板中的 `_命名说明.txt` 等占位/示例文件；
- [ ] 已附带填好的《需求单》和本清单；
- [ ] 已附一份《素材清单》：本次交了哪些、哪些复用模板、哪些暂时没有；
- [ ] 压缩包命名符合 `角色名-素材包-日期.zip`，且能在解压后直接看到上述目录结构；
- [ ] 我确认包里没有账号信息、密钥、个人隐私内容。

> 如果答案是“需要再问一遍”，请把缺的说明补进需求单或动作说明，再提交。
