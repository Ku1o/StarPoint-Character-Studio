# 稿主素材准备指南

先说明角色意图并保留原稿。制作方处理游戏编号、DSL、PNG 封装、声音编码与版本链。

## 从这里开始

1. 填角色名、资料头衔、属性、形态、定位和玩法意图。
2. 导入原稿并按用途关联；保留原文件名、原目录与可编辑源文件。
3. 一张母版可派生多个 UI 小图；进化可明确复用，不必为每个用途重复绘制。
4. 在每项声明中选择复用、可派生、不适用、请协助制作或暂时无法提供，并说明理由与参考。角色和玩法未定也可这样交接。
5. 没有配音时填写整体无配音和理由；音效单独说明。已有声音仍须有实际入口和完整台词。
6. 导出工程和制作交接，核对下面的作者补充与制作方待核。

## 状态说明

| 作者责任声明 | 下一步 |
| --- | --- |
| 直接填写或提供文件 | 尚未说明；旧工程缺省也保持未标注，不会自动通过。 |
| 请协助制作 | 说明期望结果、希望制作方协助的部分及已有参考；只完成作者意图，不表示已收到素材。 |
| 暂时无法提供 | 说明暂时无法提供的原因、可接受的替代方案及已有参考；制作方确认后续安排，资源保持缺失或待核。 |
| 明确复用 | 写清官方角色 / 资源、已有形态或工程素材来源；制作方核对映射和接入。 |
| 由母版派生 | 选择母版或写参考名称与可调整范围；制作方给派生结果和预览。 |
| 不适用并说明理由 | 写清无需求或不适用理由；制作方仍核对必要入口。 |
| 请制作方确认 | 写出具体待核问题；制作方确认实现范围。 |
| 稍后补充 | 作者补充原稿或意图；可改为明确复用、可派生或不适用并说明。 |

## 角色与玩法协助说明


作者说明完成与制作接入通过分别记录；复用、可派生、不适用和已提供都不会自动证明游戏可用。

## 原稿与动作

原始像素尺寸、每格大小、格号从 0 还是 1 开始、动作用途都要说明。逐帧记录顺序、时长、循环、返回状态和身体足底。
纯本体与含召唤物 / 附属物的合成帧分开；未画动作明确标注。旧角色的格号或配方不能作为所有角色的默认。

## 演出与声音

起手、命中与结束分别说明位置、跟随对象与时序。表现区域和实际伤害判定分开；编排预览不代表原生脚本或实战通过。
保留最高质量原声和完整句尾。制作方按同声道参考检查编码后响度、真峰、削波和时长；试听发声不代表全文或入口验收。
获取台词保留全文和手动换行，排版候选展示差异，不默默删词；近似气泡预览仍需实际首次获取验证。

## 两种称号

角色资料头衔与可佩戴玩家铭牌分开。铭牌按需求选填，可先交草图；最终 320×50 透明 RGBA，还需 160×25 缩小预览和实际内框核对。
