# 稿主素材包 · 最小模板（怎么用）

这份模板只规定“目录和命名”，里面没有任何要照抄的素材。

## 使用步骤

1. 把整个 `04-稿主素材包最小模板` 复制一份，改名为 `角色名-素材包`；
2. 填写 `00-需求单.md`；
3. 按下面目录放素材（没有改动的类别不要创建、不要塞模板角色资源）：

```text
角色名-素材包/
├─ 00-需求单.md
├─ 01-提交前自检清单.md
├─ README-素材清单.md          # 建议自己补一份：交了哪些 / 复用哪些
├─ masters/
│  ├─ base.png                 # 基础形态全身立绘（透明 PNG，≥1440×1920）
│  └─ awake.png                # 进化形态全身立绘（同上；复用基础时可不放并注明）
├─ pixelart/
│  ├─ neutral/                 # 待机（纯本体帧）
│  ├─ walk_front/              # 向前移动
│  ├─ walk_back/               # 向后移动
│  ├─ skill_ready/             # 技能准备（开大；可带召唤物，需注明）
│  ├─ kachidoki/               # 胜利
│  ├─ into_coffin/             # 倒下
│  ├─ ghost_raise/             # 灵魂出现
│  ├─ ghost_neutral/           # 灵魂待机
│  ├─ revive/                  # 复活
│  ├─ special_land/            # 获取·登场（是否带召唤物需注明）
│  ├─ special_pose/            # 获取·定格（同上）
│  └─ 动作说明.md              # 每个状态的帧数/顺序/停留/是否含附属物
├─ effect/
│  ├─ 特效声明.md              # 复用 / 重皮 / 完全原创 三选一
│  └─ source/                  # 原创或重皮时才放源素材
└─ voice/
   ├─ ally/                    # 加入 join、进化 evolution
   ├─ battle/                  # 战斗开始、技能喊声、技能就绪、强化弹射、落穴、胜利
   ├─ home/                    # 主页问候
   └─ 语音对照表.csv           # 文件 / 入口分类 / 用途 / 台词
```

4. 逐条勾完 `01-提交前自检清单.md`；
5. 删除模板里的 `_命名说明.txt`，压缩为 `角色名-素材包-日期.zip` 交付。

## 命名与格式速查

- 帧文件：`动作名_001.png`、`动作名_002.png`…（三位数，排序即播放顺序）；
- **纯本体帧不带后缀**；带召唤物/附属物的合成帧统一用 `_sp` 后缀，并且**单独放**（不要和纯本体帧混在一个目录里当一套交）；
- 只用中文/英文/数字/下划线/连字符，不要空格；
- 透明 PNG，单帧单边 ≤1022 px，不要预先放大，不要交 GIF/PSD/视频；
- 音频用标准 WAV/MP3/OGG，不需要自行转码。

详细要求见上一级目录的《01-稿主资源提供指南.md》与《02-稿主提交前自检清单.md》。
