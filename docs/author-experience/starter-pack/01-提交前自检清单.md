# 提交前自检清单（简版 · 交付前逐条勾选）

> 完整版见上一级目录《02-稿主提交前自检清单.md》。本页用于素材包内自查；不适用的条目写“不适用 + 原因”。

## 通用

- [ ] 已填《需求单》，写明哪些改动、哪些复用；
- [ ] 没交没有改动的模板资源；
- [ ] 文件名无空格、无特殊符号；帧号三位数排序即播放顺序；

## 立绘与界面

- [ ] 透明 RGBA PNG、≥1440×1920、人物完整不裁断、两形态同人；
- [ ] 五个重点面板（图标/编队/技能插入图/技能指引/技能连锁）的取景要求已写明；
- [ ] 需要特殊构图/表情的用途已单独给图，并注明“禁止自动裁切”；
- [ ] 形状遮罩（锥形/六边形/圆形/圆角）已确认：自动烘焙或自绘说明；

## 像素动画

- [ ] **基础状态（待机/前进/后退/胜利/倒下/灵魂出现/灵魂待机/复活）使用纯本体帧**；
- [ ] 带召唤物/附属物的合成帧**单独提供**（后缀 `_sp`），并写明对应状态与出现时机；
- [ ] 合成帧与纯本体帧没有混在同一目录里直接一起交；
- [ ] **获取演出（special_land / special_pose）是否带召唤物已二选一写明**；
- [ ] 每个状态的名称、用途、帧数、帧顺序、每帧停留、循环方式已写清；
- [ ] 同动作画布与定位一致；单帧 ≤1022 px；未预先放大；未交 GIF/PSD；

## 特效与音效

- [ ] 场上特效已三选一：复用 / 重皮 / 原创；
- [ ] 原创特效给的是四件套或指定骨架 + 贴图，不只是概念图；
- [ ] 音效按用途标注，并写明绑定到哪个动作第几帧；

## 语音与台词

- [ ] 语音按 `ally / battle / home` 分目录；
- [ ] 每条语音在 `语音对照表.csv` 填了：文件、入口、用途、台词；
- [ ] 注明了哪些复用模板、哪些是替换；授权已确认；

## 打包

- [ ] 删除了模板 `_命名说明.txt` 等占位文件；
- [ ] 已附《需求单》《素材清单》与本清单；
- [ ] 压缩包内无账号信息、密钥、隐私内容。
