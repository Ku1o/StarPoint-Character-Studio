# 场地预览与坐标说明

## 给创作者：先看大小，再摆位置

像素动作、特效编辑和技能预览都提供两种视图：

- **场地比例**：按固定场地边界显示。小画稿不会自动放大成“大角色”，大特效也不会自动缩小到和小特效一样大。适合比较角色大小、特效覆盖和越界。
- **素材放大**：按整段素材范围居中，适合看像素和逐帧细节；不是游戏显示尺寸。

“观看放大”和“大屏预览”只改变工作台视图，不写入素材变换。面板分开显示 PNG 原图尺寸、去掉透明边后的可见像素、当前帧的场地单位范围，以及占场地宽高的比例。可见范围包含武器、影子、光点等所有非全透明像素，不是人体或伤害判定范围。原生骨架显示当前图层边界，不冒充精确不透明轮廓。

### 调整像素小人

1. 先从时间轴选一张画稿。
2. 用“可见底边对齐”快速将画面底边中点移到紫色十字；若武器、影子低于脚底，用“点选脚底 / 中心”点选真正的定位点。它会修改这张画稿的偏移，不会裁掉源图。
3. 可以拖动选中画面或十字，也可在画布聚焦时用方向键微调；Shift + 方向键移动 10 个当前编辑单位。拖动一次只产生一次撤销，取消拖动不留下变更。
4. 逐帧检查飘移。这里只对当前画稿操作，不会把动作中本来设计好的腾空位移自动抹平。
5. 如需改变整个角色的大小，使用“统一整组角色的显示倍率”。全部像素动作（含空槽位）一起更新；游戏像素图集共用一个倍率，不应逐动作随意设置互相冲突的数值。
6. 最后查看“编译后预览”。非整数缩放和旋转会栅格化，实际输出可能有整数像素边界差异。

### 摆放技能特效

在“技能预览”中选中时间轴的一项内容，可以拖动、输入场地坐标，或点击“放在角色点 / 放在目标点 / 放在场中央”。橙色目标点是静态构图参照；“放在目标点”只移动这一项，**不会建立运行时目标追踪**。音频项不提供空间坐标。

“场地设置”可修改场地尺寸与参考点。设置随 `.wfchar.zip` 保存和交接；角色、特效的局部偏移和技能轨道不会因更换场地被自动重写。单纯打开旧工程、切换视图或观看放大不会自动补写场地数据；首次显式定位编辑会保存使用的参考场地，避免交接时失去定位依据。

“导出定位参考图”输出带场地说明和“非实战截图”标注的 PNG。它适合和美术、制作方沟通，不替代可编辑工程。

## 内置参考场地来自哪里

内置值是明确关卡的边界，不是猜测的屏幕尺寸。

| 项目 | 值 |
| --- | --- |
| 主线关卡 | 1-2-1「追蘑菇1」，quest `1002001` |
| 场地 | `main_1_2_1`，zone `1`（第 2 区域） |
| 地形逻辑资源 | `battle/terrain/main_quest/chapter_01/main_chapter_01_02_01.amf3.deflate` |
| 原始地图对象 | `/layers/1/objects/0`，type `BOUNDS` |
| 美术单位边界 | x=46, y=0, width=180, height=320 |
| 世界单位边界 | x=276, y=0, width=1080, height=1920 |
| 换算 | 世界单位 = 地形美术单位 × 6 |
| 地形资源 SHA-256 | `69e614afd435cd7eca626285e34bf2c0e6508ad8cff67952cb4317fc892a7e6e` |
| 取证 | 2026-10-08；有效资源链至 1.4.133，静态读取 |

地图画布为 272×736 美术单位，**它不等于单个区域的 BOUNDS**。同一地图的 zone 0 边界位于 (46,352)，宽高同为 180×320。当前内置只采用 zone 1 的边界；不能据此断言每个游戏关卡都是该尺寸。

坐标换算由客户端 `pinball.terrain.ZoneParser.parseRect` 的 x/y/width/height ×6 语义支持。渲染常数 `BattleConstants.SCALE_RENDERER=6`、`BattleView` 世界层的 1/6 渲染也提供交叉证据；该语义核对来自既有历史客户端导出，本次没有重新反编译或进行当前客户端设备验收。

为便于稿主摆放，本预览把该 BOUNDS 左上归一化为 (0,0)：场地内 X=0 对应该参考地图世界 X=276，场地内 Y=0 对应世界 Y=0。角色参考点 (540,1440) 和目标参考点 (540,576) 是工具选定的构图位置，**不是地图证明的官方出生点或敌人坐标**。

## 数据与实现边界

- 序列画稿的 x/y 是动画倍率之前的局部美术偏移；像素动作默认 `frameScale=6`。单张画稿的 `scale` 是额外的画稿缩放，不是观看放大。
- 技能轨道 x/y 已处于世界单位，相对于角色参考点；不可再额外乘 6。
- 在场地内输入坐标 `(X,Y)` 时，保存轨道偏移为 `(X-originX,Y-originY)`。
- 原生特效保留矩阵、trim、pivot 和图层偏移；不会重新按图片中心摆放。整体位置在技能轨道中调整。
- `previewStage` 是可选的工程元数据：version、profile、width、height、originX、originY、targetX、targetY。无此字段的旧工程保持原样；验证拒绝缺字段、非有限数、布尔值、非法版本和越界参考点。
- 编译后播放器使用同一场地坐标视图。场地元数据不改变编译出的美术资源、伤害数据、技能脚本、碰撞或目标绑定。
- 游戏镜头移动、弹射器、真实碰撞边界、地形遮挡、目标跟随、命中与条件分支不在这个预览中模拟，仍需接入游戏验收。场地比例正确不等于完整战斗还原。
