# 星点角色工坊 · StarPoint Character Studio

面向角色创作者的 Windows 本地工作台：从官方参考模板或原创工程开始，制作立绘、界面图片、像素动作、技能特效、声音与能力草稿。

**当前版本：0.8.2 预览版。** 源码与配套 Windows 工具见 [v0.8.2 预览版本入口](https://github.com/Ku1o/StarPoint-Character-Studio/releases/tag/v0.8.2)。工具基于 [kuronzzhan-droid/startpoint-cn-mod-tools（原 MOD 修改器）](https://github.com/kuronzzhan-droid/startpoint-cn-mod-tools) 开发，复用并扩展资源编码、动画预览和能力编辑实现。源码采用 GPLv3，见 [来源声明](NOTICE.md) 和 [LICENSE](LICENSE)。

## 当前源码预览：从中文步骤开始

0.8.2 预览版在选择复用参考时可以直接看已有动作、特效或试听原声音，再决定选用。复杂方案的制作步骤可分别保存“待处理、处理中、待协助、准备好待验”和具体说明；方案或参考来源变化后重新核对，旧进度仍随工程保留。“准备好待验”不会自动标记游戏行为完成。预览、进度和工程升级保留原图、声音、动作与技能程序。

复杂技能、特殊形态和召唤物方案会生成逐项制作计划：已说明的要求、还可补充或申请协助的部分、制作方的执行与验证步骤分别保留。可以按名称选择工程实际已有的技能、动作、特效或声音作复用参考，工具只读检查字节来源和固定引用，原技能与素材不改；查到参考不等于行为已接入。新增中文“增加技能槽”卡片支持明确触发、目标及最多100%的正比例，沿游戏原有获取限制，先预览再明确应用。

新建工程先进入角色设定；点击侧栏「开始与进度」，即可从「从这里开始制作角色」按中文步骤操作。最简路径是：写角色想法 → 用玩法卡片或文字说明技能 → 上传或点选已有图片和声音 → 为暂时做不到的部分写详细协助说明 → 保存并导出工程。无需输入代码、素材编号或 JSON，也不必等所有素材完成才交接。具体操作见[无代码创作流程](docs/NO-CODE-WORKFLOW.md)。

玩法卡片记录作者意图；真实文件、已说明的需求和待核验的游戏接入分别显示。可以声明无配音，使用普通表单保存音量配方、按名称选参考；本机具备可选音频处理工具时可生成独立候选并对比试听，原稿和原声保留。图片无损整理先查看对比，再主动开启，之后在支持范围内自动应用；未开启时保留原排布。素材依赖自动追踪，作者无需编辑配置 JSON。旧技术条目未完成时可以保留草稿并交接，严格编译仍会列出阻碍。

源码还包含原稿 ZIP 接收与来源追溯、像素动作说明、整角色图集审计、技能预览依据、获取台词全文与排版候选，以及独立可佩戴铭牌。详细边界见[原稿接收与制作交接](docs/WORKSHOP-UPGRADE.md)。0.8.2 为预览版本，配套 Windows 工具通过 [v0.8.2 版本入口](https://github.com/Ku1o/StarPoint-Character-Studio/releases/tag/v0.8.2)获取；完整游戏行为仍需另行验收。

当前源码支持从真实角色定义追踪主位、副位、队长、保留技能版本和形态的素材；已展开的引用、明确缺失和仍需核对的范围分别列出。部分中文能力/队长卡片可先预览，再明确选择生成真实条目，并在未发生后续词条编辑时撤回。未知机制与原始说明继续保留，不要求普通作者写代码；完整游戏依赖和实战仍需单独验收。

作者只需说明角色实际需要表现的效果，共用特效和状态图标可以复用，不用填写游戏技术开关。详细游戏公共条件的素材收集并集保留在制作方技术报告，由制作方结合实际阵容、配置和动态选择继续核对；候选齐全不代表完整游戏依赖或游戏内角色已验收。

角色工坊的稿主主流程专注 MOD 角色的图片、像素动作、技能、能力、召唤物和声音。暂停、奖励、继续游戏、商店及交易说明等通用游戏界面仅作为制作方技术报告中的依赖审计：12 个已读取入口继续沿实际格式追踪固定图片、文字控件和子资源，运行时填入的文字、奖励及货币内容仍由制作方核对，按钮跳转不会冒充图片依赖。这些公共界面不作为稿主制作缺项，不要求稿主选择沿用文字、补图或申请协助；底层检查结果也不代表游戏内角色已验收。

## 沿用 0.8.0 的场地定位与稿主交接

- **像素小人**：查看原图尺寸、可见范围和显示倍率，点选脚底/中心锚点，拖动或用方向键定位。
- **技能特效**：按参考关卡的实际场地比例摆放，可快速放到角色点、目标点或场中央。
- **预览与交接**：场地设置随工程保存，编译后预览共用坐标视图，可导出定位参考 PNG；声明入口更紧凑。

旧工程可继续迁入，原目录保留，官方资源无需重下。详见 [使用说明](docs/USER_GUIDE.md) 与 [场地定位说明](docs/SPATIAL-PREVIEW.md)。场地预览不代替真实游戏验收。

## 解压后使用

1. 从 Releases 下载 `StarPoint-Character-Studio-版本号-Windows.zip`，完整解压到可写目录。
2. 双击 `星点角色工坊.exe`；无需安装 Python 或原 MOD 修改器。`_internal/` 必须和 EXE 一起保留。
3. 选择「原创角色」，或另行安装资源包后选择「基于角色模板」。
4. 按左侧步骤制作，查看预览并导出工程。0.8.2 预览版提供中文步骤页和「检查与交接」。工程自动保存在 `projects/`，可导出 `.wfchar.zip` 备份或转交。

版本号显示在窗口标题和界面左上角，点击可查看使用提示、保存完整说明及查看来源。重复打开同一工程目录会唤回已打开的窗口；关闭窗口会先保存工程，保存失败会保留窗口。

桌面版需要 Microsoft Edge WebView2 Runtime 和 .NET Framework 4.6.2+。组件准备好后可离线制作。升级时先保存、关闭旧版并备份工程，将完整新版解压到新目录。再从新版「工程与升级」选择旧工具目录或旧 `projects/` 迁入；程序校验后复制，旧目录保留。`templates/` 和 `definitions/` 可完整复制到新版，不必重新下载。

## 工具与资源包分开

Git 源码与工具 ZIP **不包含官方角色资源或个人工程**；官方资源只作为独立 Release 附件提供。制作原创角色无需官方素材包。

官方角色资源已作为本仓库的 Release 附件提供，和工具分开下载：

| 下载项 | 说明 |
| --- | --- |
| [v0.8.2 Windows 工具 ZIP](https://github.com/Ku1o/StarPoint-Character-Studio/releases/download/v0.8.2/StarPoint-Character-Studio-0.8.2-Windows.zip) | 本版预览工具；完整解压后双击 EXE |
| [角色资源 1/2](https://github.com/Ku1o/StarPoint-Character-Studio/releases/download/v0.7.1/StarPoint-CN-Character-Resources-1.4.54-r3-1of2.zip) | 与 2/2 都要下载，内容解压到工具目录 |
| [角色资源 2/2](https://github.com/Ku1o/StarPoint-Character-Studio/releases/download/v0.7.1/StarPoint-CN-Character-Resources-1.4.54-r3-2of2.zip) | 与 1/2 都要下载，内容解压到同一个工具目录 |

资源总量约 3.49 GiB，因 [GitHub 单附件大小限制](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases)，分成两份普通 ZIP（每份约 1.74 GiB）。**两份都解压到工具目录即可，不需要合并压缩文件，也无需另装解压软件。** 选择「解压全部」时将目标设为工具目录，避免额外套一层 `1of2` / `2of2` 文件夹。

两卷装好后重新打开工具。最终目录应为：

```text
星点角色工坊/
  星点角色工坊.exe
  _internal/
  templates/       官方美术、动作、特效、声音模板
  definitions/     对应角色定义与离线词条库
  projects/        自动建立的个人创作工程
```

已安装完整 `StarPoint-CN-Character-Resources-1.4.54-r3.zip` 的用户无需重新下载；0.8.2 预览继续沿用 v0.7.1 Release 中的两卷资源附件，不重复上传相同资源。该配套版本覆盖国服 1.4.54 的 505 个角色及特殊条目，资源缺项和预览限制会在模板中分别显示。模板新建后复制为独立工程，后续编辑不会修改模板库。

页面下方的 `Source code (zip / tar.gz)` 是 GitHub 自动提供的源码；直接使用 Windows 工具无需下载它们，也无需单独下载校验文件。

## 可以制作什么

| 模块 | 主要功能 |
| --- | --- |
| 立绘与界面 | 按用途读取官方原图，基础/进化切换，从母版精确裁剪，单图导出与替换 |
| 像素动作 | 常用动作槽位，批量 PNG / 目录导入，精灵图切分，帧序、时长和变换编辑，整段播放 |
| 技能制作 | 序列特效，官方可解析特效的通道编辑与关键帧，多轨道和声音同步预览 |
| 声音与台词 | 按名称选音频、中文用途与台词、无配音说明、音量配方、声音事件编排；本机具备可选音频工具时生成候选并对比试听 |
| 作者填写包 | 角色及玩法文字、点选或上传素材、复用参考与详细协助说明、保存制作交接 |
| 技能与能力 | 中文玩法卡片与自然语言方案；有角色定义时可继续用词条库、拆解组合和六槽能力校验 |
| 复杂玩法与协助 | 中文生命比例、连击和已有屏障条件；召唤、特殊伤害与技能复用按问题说明，待核清单可追加到原填写包 |
| 检查与交接 | 作者待补与制作方待核分别显示、草稿工程、离线编译、先对比再开启的无损整理、自动依赖追踪、图集和编译回读预览 |

导入格式、尺寸、帧数和声音要求请看 [素材准备](docs/USER_GUIDE.md#美术素材如何准备)。

稿主交付流程：在「检查与交付」集中补齐素材用途声明，查看可定位的阻断/待补项，再导出附检查报告的草稿工程或离线编译候选。编译严格使用所选画稿，不按文件名自动换图；详见 [稿主交付自检](docs/USER_GUIDE.md#稿主交付自检)。

## 当前边界

这是角色制作预览版。完整官方技能的战斗还原（移动、命中、目标、镜头、条件分支）尚未完成；部分复杂原生特效仍有渲染限制。工具会显示具体限制，不能将素材播放视为完整战斗验收。

创作者可以交出工程和离线编译产物。正式游戏 ID、角色主表与玛纳板、客户端专用 UI 图集和 Android/iOS 资源绑定仍由接入方完成。工具不修改玩家存档，也不直接把角色发布到游戏。

与原 MOD 修改器共用制作服务、工程格式和核心实现；在已接入角色工坊的 MOD 版本中可继续编辑同一工程。接驳方式见 [MOD-INTEGRATION.md](MOD-INTEGRATION.md)，预览实现与缺口见 [PREVIEW-RUNTIME.md](PREVIEW-RUNTIME.md)。

## 从源码运行

建议使用 Windows 与 Python 3.13；本版在 Python 3.13 验证。源码自带 `core/`，不需要私有服务端仓库。

```powershell
python -m pip install -r requirements-desktop.txt
python studio.py --open
```

资源目录可用 `--templates <目录>` 和 `--definitions <目录>` 指定，工程目录用 `--projects <目录>` 指定；`--no-open` 只启动本机服务，供浏览器调试。

开发检查和 Windows 打包见 [GITHUB.md](GITHUB.md)。Windows ZIP 同时携带对应源码及第三方许可；官方素材、个人创作与软件源码分别管理。
